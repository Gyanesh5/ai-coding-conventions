# 前端界面规范

工业场景 Web 前端（Vue3 + ElementPlus + ECharts）：监控、报警、参数配置、检测显示、日志、大屏。目标是密度与可用性优先，界面禁止呈现 AI 生成的默认样式（AI 默认紫渐变/Inter/三卡片，业内称 AI slop）。

对外营销官网不适用本文件。

---

## 设计 Tokens（唯一合法取值）

### 中性色（暗色主题，默认）

| Token | 值 | 用途 |
|---|---|---|
| `bg-base` | `#0F1214` | 页面底 |
| `bg-surface` | `#171C20` | 卡片、表格、面板 |
| `bg-raised` | `#1F262B` | 弹窗、下拉、hover |
| `border` | `#2D373E` | 1px 分隔线 |
| `text-primary` | `#E6EDF3` | 主文字 |
| `text-secondary` | `#9BA6B0` | 次级文字、单位、时间戳 |

### 中性色（亮色主题，白班办公页可选）

| Token | 值 | 用途 |
|---|---|---|
| `bg-page` | `#F5F6F7` | 页面底 |
| `bg-surface` | `#FFFFFF` | 卡片、表格 |
| `border` | `#D9DEE3` | 分隔线 |
| `text-primary` | `#1F262B` | 主文字 |
| `text-secondary` | `#57606A` | 次级文字 |

### 语义色（全站只有这四种状态色，颜色只表达设备/数据状态）

| 语义 | 暗色 | 亮色 | 唯一用途 |
|---|---|---|---|
| 运行 / OK | `#3FB950` | `#1A7F37` | 设备运行、检测通过 |
| 停止 / 待机 | `#8B949E` | `#57606A` | 设备停止、无数据 |
| 报警 / NG | `#F85149` | `#CF222E` | 报警、NG、越限、破坏性操作 |
| 警告 | `#D29922` | `#9A6700` | 可继续但需注意 |

### 强调色（accent，全站唯一，只用于交互：链接、选中态、焦点环、实时数据指示）

暗色 `#3FB8AF`，亮色 `#0E7C76`。

### 取色规则

- 上表 18 组前景/背景对比度按 WCAG 公式实测全部 ≥4.5:1。**替换任何色值必须重算对比度，禁止拍脑袋换色**
- 禁止规范外颜色。禁止一切渐变（背景/文字/按钮）、玻璃拟态、发光效果
- ElementPlus 默认蓝 `#409EFF` 必须通过 `--el-color-primary` 覆盖；语义色映射到 `--el-color-success / warning / danger`
- ECharts 统一 `registerTheme('plant', {...})`，色板从本表派生，禁止默认色板
- 好数据不着色：正常值一律 `text-primary`，只有越限/NG 才上语义色
- 强调色同屏只做一类事（全是交互或全是数据指示）

## 字体

| 用途 | 字体 |
|---|---|
| 拉丁正文 | IBM Plex Sans |
| 数值/代码/坐标 | IBM Plex Mono（等宽，表格数字滚动不跳宽） |
| 中文 | Noto Sans SC（系统回退） |

禁止 Inter / Roboto / Open Sans / system-ui 作为界面字体。

| 级别 | 值 |
|---|---|
| 正文/表格 | 13px |
| 辅助/单位/时间戳 | 12px |
| 区块标题 | 16px / 600 |
| 页面标题 | 20px / 600 |
| KPI 大数字 | 24–28px Mono / 500，同屏 ≤4 个 |

- 字重只用 400 / 600，禁止斜体
- 所有数值（坐标、节拍、电流、计数）一律 Mono + 右对齐；单位 `text-secondary` 紧跟数值

---

## 布局与密度

- 间距只用 4 的倍数：4 / 8 / 12 / 16 / 24 / 32
- 圆角三档：控件 4px、卡片 6px、表格单元格 0。禁止 8px 以上
- 阴影只用于浮层（弹窗/下拉/tooltip），平面卡片用 1px `border` 分隔
- 骨架：顶部状态栏（连接状态灯 + IP + 用户 + 时间）+ 左侧窄导航（≤7 项，可折叠）+ 主区
- 主区主次分栏代替居中堆叠：左图右表、上概览下明细、左树右参数。禁止单列居中排队布局
- 密度参数：表格行高 36px（密集 32px）、ElementPlus 控件 `size="small"`、卡片内边距 12–16px、页面内边距 16px
- 监控页信息分层：总貌层只有色块状态 → 区域 → 单元（布局对应设备物理形态）→ 参数 → 原始数据。先确定页面属于哪一层再动手
- 检测结果页：相机画面 ≥60% 视口，overlay 直接画在画面上、数值紧贴标注，OK/NG 用语义色边框+文字，不另做弹窗

## 禁止出现的 AI 默认模式（出现即返工，不手工修补）

```
❌ 三列/四列等宽功能卡片网格
❌ 卡片套卡片（card-in-card）
❌ 统计卡片横排一行 + 每张配图标 + 图标带彩色底
❌ 居中大标题 + 上方 pill 小徽章 + 标题里一个词着色
❌ 全页滚动 fade-up 入场动画
❌ emoji 当功能图标（图标统一 Lucide，状态图标颜色跟语义色）
❌ 渐变、玻璃拟态、紫色/靛蓝色、霓虹发光、呼吸/粒子动画
❌ ElementPlus / ECharts / Tailwind 默认色板
❌ 营销页式大留白用在操作页
```

## 数据呈现

- 单位必写：mm、mm/s、ms、°、V、A、Hz。无单位数字不允许上界面
- 空值显示 `—`，禁止显示 0 或留白（0 是数据，空是没数据）
- 精度固定且同列一致：坐标/尺寸 2 位小数、节拍 ms 整数、比例 1 位
- 时间戳 `HH:MM:SS`（跨天 `MM-DD HH:MM:SS`），禁止"3 分钟前"
- 实时数值刷新不加动画不闪烁；越限判定在数据层、着色在展示层，阈值从配置读
- 曲线 >4 条改分面；kHz 级高频曲线用 uPlot，常规统计 ECharts
- 表格（vxe-table）：斑马纹关闭、hover 行高亮用 `bg-raised`、坐标列等宽

## 状态设计（每个数据区域强制四态）

| 状态 | 表现 | 禁止 |
|---|---|---|
| loading | 骨架屏（按行/按块），>300ms 才出现 | 整页 spinner、白屏 |
| 空 | `—` + 一行说明 + 引导动作 | 假数据垫着、图表画 0 |
| 错误 | 哪台设备、什么错、错误码 + 重试按钮 | "出错了请稍后再试" |
| 离线 | 设备灰色 + 最后通讯时间 | 当空数据、清空页面 |

**断线不清屏**：状态/帧/命令任一通道断开，保留最后一帧数据 + "数据停滞于 HH:MM:SS"标注 + 重连指示，恢复后无感续上。数据消失比数据错误更不可接受。

报警交互：分级列表 + 未确认计数徽章 + 确认 + 重弹；报警置顶 + 语义色 + 声音（可静音），非 CRITICAL 禁止 modal 弹窗打断操作。

## 动效（只允许三种用途）

| 用途 | 例子 | 参数 |
|---|---|---|
| 状态变化反馈 | 开关、模式切换、确认 | 150–200ms ease-out |
| 数据更新指示 | 新报警滑入、计数滚动 | 200–250ms |
| 层级引导 | 弹窗/抽屉/下拉 | 200–250ms |

禁止：滚动入场动画、视差、弹性/回弹 easing、循环装饰动画、无事件的 hover 放大。`prefers-reduced-motion` 关闭非必要动效。大屏允许"数据在动"（曲线延伸、数字滚动、状态灯变化），禁止"装饰在动"（粒子、流光、无数据对应的飞线）。

## 文案

- 形容词配额 = 零：高效/智能/强大/一站式/赋能禁止出现，能力用数字说（"节拍 4s""拍一张 200ms"）
- 按钮动词开头（"重新标定""下发配方"），禁止"确定/提交"用在有明确动作的场合
- 标题名词短语，禁止口号式
- 报警文案模板：`[工站] [设备] [现象(含量)] [建议动作]`，例："3号工位 相机1 采集超时(2000ms) 检查触发信号"
- 错误文案：现象 + 原因（若知）+ 动作
- 术语统一：OK/NG、运行/停止/报警/离线，全站不混用
- 界面多余的标语、说明文字、次要标签一律删除（布局问题改布局，禁止加文案补救）

---

## 展示大屏

- 暗色主题 + 本规范 tokens，不另开色板
- 总貌色块 + 趋势 + 一个实时细节区，区块数 ≤5
- 字号起步 16px，KPI 32–40px；3m 观看距离正文 ≥20px
- three.js 只用于有真实数据映射的场景（设备布局、机器人姿态），禁止装饰性 3D

---

## 生成前上下文要求（AI 行为）

生成任何页面前必须具备：页面类型（操作页/大屏）、信息层级、真实字段清单（含单位）、2–3 行真实格式数据样例、参照范式（如"海康 VM 四区""AUBO 配置页""总貌色块图"）。缺真实数据时先向用户要，禁止用编造数据占位。

验收不通过打回重新生成，禁止手工修补默认值（手补会留半张 AI 脸）。

---

## 验收清单

1. 主色与图表色板来自本 tokens，非任何库默认值
2. 全页无渐变、无玻璃拟态、无紫色/靛蓝
3. 无等宽卡片网格、无卡片套卡片、无统计卡横排+彩色图标
4. 数值全部 Mono + 单位 + 右对齐
5. 每个数据区域四态齐全
6. 断开 WebSocket 页面不清空，显示"数据停滞于 HH:MM:SS"
7. 颜色只出现在语义位置，正常数据不着色
8. 文案形容词为零，报警文案含建议动作
9. 空值显示 `—` 不是 0
10. 间距全为 4 的倍数，圆角 ≤6px
11. 无滚动入场动画、无循环装饰动画
12. 暗色正文对比度 ≥4.5:1（换过色的组合必须重算）
